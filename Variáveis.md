variável é um valor, número ou objeto que definimos com um nome, que são os tipos primitivos.

O símbolo de "=" significa "recebe".

```jsx
var numero = 2; //number, não usa aspas

var palavra = "paralelepidedo"; //string, mesmo se colocar um número, a string é definida pelas aspas ""

var objeto = []; //array, definido pelos conchetes

var array = {}; //object, definido pelas chaves
```

var: é um valor global, ele pode ser chamado mesmo se estiver dentro de uma função. E o valor dele pode ser alterado também

let: é um valor mais respeitado, ele global, existe até para as funções, mas se ele estiver dentro de uma função, ele só existe lá. Porém, ele pode ser alterado também.

const: é uma variável que, quando declarada, não tem como mudar o valor. É a forma mais segura de usar uma variável.

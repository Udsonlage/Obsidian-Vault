for in - É usado para somar ou pegar todos os índices(posição) de um array

```jsx
let res = 0 //variável que vai receber a soma de todos os arrays.

for(let i in inventario) { //criou uma variável para o indice com o valor 0, que representa o 1° array
        res += inventario[i] //somando todos os arrays, posição por posição. [i]
    }
```

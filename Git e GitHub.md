Antes de começar a codar, preciso rodar no terminal:

`git pull` - puxa todas as alterações de uma das máquinas. A mais recente.

`git add .` - Pega todas as alterações e empacota.

`git commit -m "comentário"` - Coloca o comentário junto com as alterações.

`git push` - Sobe todas as alterações para o Github.
